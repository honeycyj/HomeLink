# HomeLink

面向 Apple Silicon Mac 的 macOS 26 及更新系统的菜单栏远程连接工具，使用 SwiftUI 原生场景、Settings 和 Liquid Glass。

客户端通过菜单栏连接，支持保存多台设备、同时连接一台。远程 Mac 使用系统自带的远程登录和屏幕共享；可以手动授权公钥，也可以选装同一个 HomeLink，通过「本机访问」添加公钥和管理 Cloudflare DDNS。

**当前状态：可自行安装的未公证测试版。** 使用者需要自行允许首次打开，详细操作见下文。公网连接仍需预先配置可达的地址和端口，或使用 VPN。

源码采用 [MIT 许可证](LICENSE)。

## 环境要求

- 使用：Apple Silicon（M 系列）Mac，macOS 26 或更新版本。
- 开发与打包：Xcode 27.1 或更新版本；不依赖第三方 Swift 包。

## 运行

用 Xcode 打开 `HomeLink.xcodeproj`，运行目标选择 **My Mac**。也可执行：

```sh
./script/build_and_run.sh --verify
```

此脚本统一负责停止旧实例、构建和启动；支持 `--debug`、`--logs`、`--telemetry`。Codex 的项目 Run 操作配置在 `.codex/environments/environment.toml`。

应用有意只显示在菜单栏，不显示 Dock 图标。没有设备时，首次启动打开添加窗口。通过菜单栏的链条图标打开设备列表。

修改界面后，在 Xcode 按 `⌘.` 停止、`⌘R` 重新运行，再展开菜单查看。如果旧版是独立打开的，先从菜单中退出旧版。共享的 HomeLink Scheme 已包含在工程中，克隆后可直接构建和归档。

默认保留固定本机开发签名，尚未完成 Developer ID 分发签名和苹果公证。目标 Mac 首次启动可能被系统拦截：确认来源可信后，先尝试打开应用，再到“系统设置 → 隐私与安全性”选择 HomeLink 对应的“仍要打开”，自行确认。受管理的电脑可能不允许此操作，详见 [苹果操作说明](https://support.apple.com/zh-cn/102445)。安装包内也附带这份指引。

安装包只含应用，不包含当前 Mac 的设备、私钥或信任记录；目标 Mac 需单独添加设备并在远程 Mac 授权自己的公钥。“允许打开应用”和“远程 Mac 授权公钥”分别完成一次即可开始使用。

## 本机开发签名与钥匙串

本机使用固定的 `HomeLink Local Development` 代码签名证书。签名私钥在登录钥匙串中，`Configuration/Local.xcconfig` 仅记录公开的证书指纹，该文件已忽略提交；没有添加系统根信任。`Debug.xcconfig`、`Release.xcconfig` 和运行脚本共用本机配置与同一个身份，避免临时签名的代码哈希变化导致反复授权。

旧版本的钥匙串授权首次切换到固定签名时，可能需要在系统弹窗输入 Mac 登录密码并选择「始终允许」。SSH 密钥与 Studio 授权无需更换。运行脚本找不到已固定的证书时会停止，不会静默切回临时签名。此签名用于本机开发，不代表已完成分发签名或公证。

`./script/test_keychain_signing.sh` 用一次性项目测试两个不同代码版本能否在不弹出授权界面的条件下访问同一个钥匙串项目，不读取设备私钥。

## 已实现

- 保存多台设备，编辑名称、地址、用户名，移除本机设备记录。
- 首台设备生成 Ed25519 密钥；后续添加默认复用已有公钥，高级选项可改为新密钥。私钥存入本机钥匙串，每台设备有独立存储项目，移除一台设备不会破坏其他设备复用的密钥。
- 设备的「… → 设备设置」始终可进入，连接中也能复制公钥和完整终端授权命令；每台远程 Mac 仍需分别授权一次。
- 首次授权页支持复制公钥到远程 Mac 的 HomeLink，也保留可复制的终端授权命令；连接时可取消，取消后保留在授权页继续设置或重试。
- 授权命令按公钥类型和内容去重，保留其他授权；附带 SSH 安全建议注释，不自动修改服务器策略，也不增加安全检查向导。
- 系统 OpenSSH 公钥认证、本机回环地址屏幕共享隧道、主动断开及单连接切换。
- 点击未连接设备建立隧道，点击已连接设备直接打开原生屏幕共享；“打开屏幕共享”按钮仍保留。
- 首次记录主机身份，后续变化时拒绝连接，不自动覆盖信任记录。
- 原生 Settings、可选登录启动；连接中断在菜单栏设备状态中显示。
- 可选本机访问：设备卡片、系统三点菜单、重命名、查看公钥、确认后撤销指定公钥。
- 可选 Cloudflare DDNS：自定义间隔、每天/工作日/每周多个时间点、唤醒及网络恢复后补查、地址不变时不写入。

添加设备只填写名称、地址和用户名；端口与公钥复用放在高级选项。只走公钥授权，不收集或保存远程账户密码。

## 在 Studio 管理本机访问

在 Studio 安装 HomeLink，打开「设置 → 本机访问」，点击「设备授权管理」右侧的「授权」，在小型原生确认框中选择「允许」。无需选择文件夹，也不请求管理员密码。成功后点击「添加设备」，填写客户端名称并粘贴客户端的完整 Ed25519 公钥；已有设备时使用标题旁的系统「＋」按钮继续添加。也可先填写设备，再在首次添加时按提示确认。应用记住这次同意，之后不重复提示，没有额外的管理总开关。

此 GitHub/DMG 版本采用非沙盒分发，保留代码签名和钥匙串。小确认框是 HomeLink 的操作同意，并不是系统文件权限或钥匙串密码验证；系统仍执行账户文件权限和隐私保护。非沙盒应用拥有当前账户可用的更广文件访问能力，不具备 App Sandbox 的文件隔离。公钥管理功能在取得同意前不读取或修改授权文件，取得同意后只维护当前账户的 `.ssh/authorized_keys`，不读取其他客户端的私钥，不修改系统 SSH 配置。公钥按类型及内容去重，备注不同也不会重复添加；保留其他公钥、注释和已有的公钥限制。写入前保存一份 `authorized_keys.homelink.backup`，目录权限为 700、文件为 600。遇到符号链接、异常文件或其他程序同时修改时停止操作。

重命名只修改 HomeLink 的显示名称。移除设备需要确认，会撤销对应公钥；多台客户端如果共用同一公钥，也会一并失去新建连接的权限。管理公钥不会自动开启或关闭系统共享。

系统的「远程登录」和「屏幕共享」仍需在共享设置中开启并允许目标账户。「本机访问」会只读检查系统服务配置、当前账户的服务访问列表和本机 SSH/RFB 服务响应，已开启时显示状态，未开启或需要确认时显示对应的系统设置入口。服务响应不等于公钥认证或桌面控制成功；公钥文件管理授权作为单独一行显示。系统查询受限或连接失败时不会推断已授权或已关闭。打开页面、从系统设置返回时会自动检测，页面内不再提供刷新按钮。检查有短时缓存、并发去重和取消处理，协议响应到达即结束；不持续轮询，也不自动修改共享开关。

设置首页统一提供原生的「登录时启动 HomeLink」开关，本机访问和设备设置页不重复展示。它在用户登录后启动应用，不是登录前的系统守护。状态来自系统登录项；待批准时显示提示和系统设置入口，从设置返回会重新读取。

## Cloudflare DDNS

此功能默认关闭，建议只在家庭网络中的 Studio 启用。先在 Cloudflare 准备一条目标域名的 IPv4 A 记录，设为「仅 DNS」，并创建仅限目标区域的 API Token，权限为 DNS 编辑及区域读取。填入域名和令牌后先只读验证，再由用户确认域名与公网地址后启用。令牌保存在独立钥匙串项目，不写入配置文件或日志；后台读取禁止弹出密码授权窗口，授权不足时暂停更新并显示错误。

DDNS 页面在公网 IPv4 地址框旁提供「检测」按钮，不填域名或 Token 也能只读检测。点击标签旁的说明图标可查看 Shadowrocket 直连设置并复制规则。应用优先使用 Amazon Check IP 与 OpenDNS 交叉核对；可用来源不足时尝试 ipify 和 ident.me 的 HTTPS IPv4 接口。至少两个来源返回相同地址且所有有效结果无冲突才会通过，检测完成后再验证并启用。备用来源的国内直连可用性取决于实际网络。DNS 查询复用 macOS 自带的 dig，无需 Python、Homebrew、UPnP 或其他安装。

使用 Shadowrocket 等分流代理时，将以下精确规则放在宽泛代理规则之前，并使用配置模式。HomeLink 不自动修改代理配置，可点击公网 IPv4 旁的说明图标复制规则：

```ini
DOMAIN,checkip.amazonaws.com,DIRECT
DOMAIN,myip.opendns.com,DIRECT
IP-CIDR,208.67.222.222/32,DIRECT,no-resolve
DOMAIN,api.ipify.org,DIRECT
DOMAIN,4.ident.me,DIRECT
```

启用代理本身不会阻止检测；失败或无效的来源不计入有效结果；有效结果冲突或不足两个来源时，停止更新，不退化为单一来源。首次启用仍须与路由器当前公网 IPv4 核对：两个来源一致也不能独立证明没有经过代理。系统的物理接口与网关 ARP 身份用于绑定已确认的网络，不将 VPN 的虚拟接口误当成家庭网关，不主动探测或修改路由器。家庭网关身份变化后暂停写入。旧版网络指纹不会自动迁移，升级后如提示网络不同，暂停并重新验证以重新确认。

只有 IP 改变时才向 Cloudflare 提交仅包含 IP 的更新，保留 TTL、代理状态和其他记录；不创建记录、不处理 AAAA 或多 A 记录。不确定更新结果时显示「更新结果待确认」，下一次重新读取确认。接口采用 [Cloudflare DNS Record API](https://developers.cloudflare.com/api/resources/dns/subresources/records/methods/edit/)。

计划支持 1 分钟至 7 天的间隔，或每天、工作日、指定星期的多个时间点。按 Mac 本地时区执行，时区变化时重新计算。可选启动、唤醒或网络恢复后补查一次，错过多个任务不反复补跑。失败时逐步延迟重试，并尊重接口限流。暂停会取消检查和计时任务；应用退出或 Mac 睡眠时不执行，不安装后台守护、不唤醒 Mac。需要长期更新时可启用现有的登录启动。

DDNS 不解决运营商共享公网地址，也不会自动配置路由器端口映射、VPN、系统 DNS 或 SSH 安全策略。

## 实际连接

在远程 Mac 开启远程登录和屏幕共享，并允许指定用户访问。将本机公钥追加到该用户的 `~/.ssh/authorized_keys`。公网访问仍须预先配置可达地址、端口映射或 VPN。

SSH 隧道只监听 `127.0.0.1`，不直接将屏幕共享对外公开。点击「打开屏幕共享」时调用系统客户端；系统可能另外要求远程账户认证。`已连接` 表示 SSH 认证和本地转发监听已建立，不保证远端屏幕共享已启用。

新安装的设备资料保存在当前账户的 Library/Application Support/HomeLink 下。若发现旧沙盒版的数据目录，则继续在原目录中读写设备、主机指纹与 DDNS 配置，不覆盖、不合并设备文件；仅补充导入设备显示名称，不再迁移已取消功能的偏好。钥匙串服务和应用标识保持不变。移除客户端保存的远程设备不会撤销 Studio 上已录入的公钥。不同客户端需要分别授权各自公钥。

## 实现约定

设置使用原生分组表单与 GroupBox，授权方式、时间和设备操作分别使用系统 Picker、DatePicker、Menu 与确认框；遵循 [Apple 原生组件适配指南](https://developer.apple.com/documentation/TechnologyOverviews/adopting-liquid-glass)，由系统提供当前 macOS 的材质和控件外观。登录启动只保留一个入口，已取消的通知、管理总开关和密码占位不再提供。

- `DeviceRepository` 维护界面快照，`DeviceFileStorage` 在专用后台队列串行读写 JSON；`ConnectionController` 负责单连接请求与状态；`DeviceStore` 协调现有界面和设置。
- 连接状态统一为未连接、连接中、已连接、断开中、失败。切换设备先等待前一次清理完成；被取消或过期的回调不会覆盖新连接。
- 正常退出等待隧道收尾。客户端本地进程守护通过私有管道监测 HomeLink 存活，意外退出时终止自己的 SSH 子进程并清理临时密钥；下一次启动还会清理专用临时目录中的遗留文件。不会操作其他终端的 SSH 会话。
- `./script/test_connection_lifecycle.sh` 覆盖取消、切换、提前退出、终止升级、客户端被 SIGKILL、临时文件清理和旧设备文件兼容。所有进程故障测试使用本机假 SSH，不修改远端配置或真实设备密钥。

- 私钥不出现在设备 JSON、日志、剪贴板或远端命令中。
- 仅在 SSH 认证期间从钥匙串取出临时私钥文件，目录权限 700、文件权限 600；认证后清理。
- `Process` 传递独立参数，不将地址或用户名拼入本地 shell 命令。
- SSH 配置、known_hosts 和身份文件由应用管理，不读取用户的全局 SSH 配置或 agent。
- 使用非沙盒的 GitHub/DMG 分发方式；SSH 转发监听地址仍限制为回环地址，不开放公网屏幕共享端口。
- 参考 Figma 的控件结构、蓝色与间距，系统负责 Light/Dark、菜单和窗口材质。设备使用原生 SF Symbol 显示器图标；未连接为半透明灰底，连接完成后为蓝底白图标。

## 后续开发

- 工程边界与扩展方式见 `ARCHITECTURE.md`。保留单个应用 target，按职责拆分文件。
- 钥匙串、设备 JSON、临时密钥均通过后台服务处理；设备变更使用类型明确的 mutation，避免异步保存时丢失其他操作。
- 诊断日志在内存中保留最近 128 KiB，通常每 500 ms 合并写盘；连接失败、退出和断开时等待最终保存。Studio 可选安装同一应用管理授权及 DDNS，客户端连接仍不依赖它，也不修改网络设置。
- 公钥、授权命令、复制反馈由共享组件实现，添加设备与设置页保持一致。
- 换开发电脑时将 `Configuration/Local.example.xcconfig` 复制为 `Configuration/Local.xcconfig`，填写该电脑可用的代码签名证书指纹。证书私钥应留在钥匙串中，不能提交到工程。
